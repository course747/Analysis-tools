# Ad Spy Tool
1. Node.js 18+ इंस्टॉल करें
2. `npm install`
3. `.env.example` को `.env` नाम से कॉपी करें, APIFY_TOKEN भरें
4. `npm start` -> http://localhost:3000
डीबग: http://localhost:3000/api/search?platform=facebook&q=shoes&raw=1 पहला कच्चा रिज़ल्ट दिखाता है।
हर सर्च Apify क्रेडिट खर्च करती है (~$0.006 प्रति ऐड)।
